- Preserve the light lavender surface, blue accents, Space Grotesk headings and DM Sans body type.

- Preserve BeatCastle privacy policy wording, app-ads.txt and existing URLs.
- Responsive and keyboard-accessible pages; unique metadata, sitemap and internal links.
- Publish the verified redesign to the existing GitHub Pages website; do not publish game builds or invent store/download links.

Alternatives considered in the preceding proposals: dark fantasy, light studio, retro arcade. The user chose light studio, which supports multiple games without tying the whole site to BeatCastle.
